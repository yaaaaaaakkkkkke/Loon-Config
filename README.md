# Loon-Config

个人 Loon 配置文件。

- **结构风格**参考 [sooyaaabo/LoonLab](https://github.com/sooyaaabo/LoonLab)（分区 `.lcf`、按地区旗帜分组、远程规则/插件）。
- **分流策略**参考 [IBL3ND/Egern](https://github.com/IBL3ND/Egern)：DNS 上游、GeoIP/ASN 数据源、国内直连规则集（ChinaMax / ChinaIPs）、LAN 域间路由。

## 订阅链接

```
https://raw.githubusercontent.com/yaaaaaaakkkkkke/Loon-Config/main/Loon_Config.lcf
```

## 使用说明

1. Loon → 配置 → 使用上方链接导入。
2. `[Remote Filter]` 已按地区（香港/台湾/日本/韩国/新加坡/美国/冷门地区）自动分组节点，导入订阅后自动归类。
3. 图标库来自 [sooyaaabo/IconLibrary](https://github.com/sooyaaabo/IconLibrary)。
4. `[MITM]` 默认留空，按需自行填写 hostname 与证书。

> 仅供个人学习参考。
